# Hisense L9Q — Calculateur d'offset vertical

Outil 100% hors-ligne (single HTML file) pour calculer le décalage entre le bas de l'image et la lentille / le meuble. 80″ → 200″. Mobile + desktop.

## Utilisation

Ouvrir `l9q-vertical-offset.html` dans un navigateur, ou via GitHub Pages (voir ci-dessous).
